* wene
Wene es un sistema Web para generar, notificar y almacenar certificados digitales.

* Instalación

1. Clonar repositorio:
   
   : git clone  https://github.com/pkogan/wene.git

2. \warning{} Para PHP 8 o mayor, se deben remover de file:composer.json los paquetes codeception dentro del grupo "require-dev". Estos paquetes no son compatibles para esa versión de PHP.

3. Instalar bibliotecas de PHP con composer.

   : composer install

4. Crear base de datos y configurar la conexión al SGBD

   En MariaDB o MySQL, ejecutar (cambiar usuario y contraseña):

   : $ mariadb -u root -p
   : CREATE DATABASE wene;
   : CREATE USER 'wene'@'localhost' IDENTIFIED BY 'wene';
   : GRANT ALL PRIVILEGES ON wene.* TO wene@localhost;

   Para configurar la conexión al SGBD, editar file:config/db.php.
   
5. Popular la BD.

   : mariadb -u wene -p wene < bd/wenelimpia.sql

6. \warning{} Agregar columna idExtranjero a la tabla persona.

   Este es un error de desarrollo a corregir.

   : alter table persona add column idExtranjero varchar(15) default null;

7. Crear el directorio file:tmp/ dentro del repositorio.

   : mkdir tmp

8. Ejecutar servidor de desarrollo.
   
   : ./yii serve

* Correos electrónicos
Los administradores pueden asignar a cada dependencia un correo electrónico con el cual se envían notificaciones. 

* Roles y usuarios

** Roles
Roles del sistema (entre paréntesis el nombre como figura en el sistema)

- administrador (Admin) :: Puede gestionar usuarios, dependencias, templates y tipos de certificados.
- gestoras/es (Gestor) :: Puede gestionar actividades, personas y certificados.
- hacedoras/es (Hacedor) :: Puede gestionar actividades.
- certificantes (Certificante) :: Puede ver sus certificados.
- invitada/o :: Puede validar (ver) un certificado.

** Usuarios y Personas
En la base de datos hay dos tablas diferentes, a saber:

- usuarios :: Contiene los usuarios que pueden utilizar el login.
- personas :: Personas que reciben los certificados generados.

La asociación entre personas y usuarios se realiza por medio del registro. Esto permite realizar certificados a personas sin necesidad de que tengan una cuenta o que tengan acceso al sistema en sí. Sin embargo, quien desee tener acceso y ver un listado de sus certificados puede registrarse y asociar su persona a su usuario.
